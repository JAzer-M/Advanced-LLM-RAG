## 3. 发现的问题及证据

q1 初始回答讲到了更多非线性和参数减少，但只写“用三层 3×3 代替单层 7×7”，没有明确说它们对应相同的 7×7 有效感受野。原文已在 [10] 中，不是缺少证据。

q5 初始回答包含 `VGG uses very small 3 × 3 convolution filters in all layers`，随后又说某配置使用 1×1。上下文 [4] 已提供例外，问题是综合与限定，而不是卷积核数值解析失败。

在真实 q5 答案上运行的最小反例检查失败：

```python
assert not ('in all layers' in answer and '1 × 1' in answer)
# AssertionError: Observed q5 scope conflict: all layers vs 1x1 exception
```

该检查只捕获这次已观察到的措辞组合，不是通用语义判定器。

按顺序检查三个假设：提示未强调解释完整性；提示未要求合并例外；检索缺少所需证据。原文核对排除了本次的第三种情况，因此不调整检索、Gold、索引或手工指定 Chunk。

## 4. 固定证据的三轮调试

每轮只重跑 q1/q5 最终生成，复用初始 context/ledger/Top-10，不重新检索；模型看不到 reference_answer、Gold 或人工评价。

| 轮次 | 改动 | 实际观察 |
| --- | --- | --- |
| prompt_v1 | 回答规则增加“覆盖原因、保留例外” | q1 仍未明确感受野；q5 仍复述 all layers，未解决 |
| prompt_v2 | 更明确要求等价关系与例外合并 | 两处仍有同类遗漏，未解决 |
| prompt_v3 | 将简短综合检查放到上下文和问题之后 | q1 明确写出 7×7 有效感受野；q5 本次仍保留 all layers |

三轮共 6 次 API 调用，均原样保存在 `prompt_v1/`、`prompt_v2/`、`prompt_v3/`。没有把失败结果删掉、改写为成功，或加入针对 VGG 的答案字符串替换。

当前 `build_prompt()` 保留第三轮的通用检查：明确来源支持的等价属性与数量；将主要规律和配置例外一起说明；减少无依据的名称与背景。这是有限改善，未验证为稳定的语义约束。
