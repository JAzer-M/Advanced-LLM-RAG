# PaperLens · 读见依据

2026-10-23 从空白重做的本地 Web UI。页面、样式和交互均为新实现；原 `ui_prototype/` 保留。

## 启动

Mac 可双击桌面的 **PaperLens 启动.command**，或 [start.command](start.command)：自动启动服务并打开默认浏览器。使用期间保持启动终端打开。也可访问 [新版研究台](http://127.0.0.1:8849)。也可以在项目根目录运行：

```bash
.venv/bin/python -B -u webui/server.py
```

只监听本机 `127.0.0.1:8849`。旧版仍使用 8848，两者互不覆盖。关闭启动终端会停止服务；网页地址本身不会启动 Python。

## 本版体验

- 全新首页、三模式提问、默认关闭的 arXiv 开关。
- 三个真实案例，回放不调用模型。
- 桌面回答与证据双栏，窄窗口上下阅读；引用定位、展开原文、全部证据。
- 论文库搜索、答案复制、运行记录和真实调用成本。
- 同一页签保留草稿与最近任务编号；服务仍运行时刷新可接续，**不会重新提交问题**。
- 模型请求发送前锁定控件；服务端同一时间只接受一个任务。

实时提问使用现有私有 API 配置，会产生模型调用费用。首页、论文库、案例回放和轮询均不调用模型。固定八篇、1397段知识库，不改激活指针。新运行存入 `logs/webui/`。

## 文件分工

| 文件 | 职责 |
| --- | --- |
| `index.html` | 全新信息结构、首页、回答阅读区和弹窗 |
| `style.css` | 纸面/墨色/朱橙视觉、CSS纸张插图、响应式布局 |
| `app.js` | 页面状态、渲染、引用交互、任务轮询及刷新恢复 |
| `server.py` | 本机静态文件与任务接口；独立日志目录、单任务保护 |
| `test_server.py` | 11项行为检查（含本机连接回归），不调用模型 |

适配层复用 `ui_prototype.app` 中的公开字段转换、元数据、案例读取和 worker 函数；不读取旧 HTML/CSS/JS。旧目录仍是这几个后端函数的来源，暂时不要删除。之后若决定退役旧页面，再单独抽出共享服务函数，避免本轮扩大重构。

## 验证与边界

```bash
.venv/bin/python -B -m unittest webui.test_server -v
```

原9项及追加2项连接/并发检查共11项通过；浏览器检查1280px、622px和390px布局。一次真实RAG提问为16.28秒、2请求、3054 token。用户追加的Agent+arXiv验收也已通过：Mamba搜索/PDF均HTTP200，48.89秒、8模型请求、24836 token，答案引用经原文核对。两次合计10模型请求、27890 token。完整记录见 [开发日志](../docs/WEBUI_REBUILD_2026-10-23.md)。

本版没有上传入库、多用户、账户、跨服务重启的会话恢复、流式输出或公网部署。服务重启后任务ID不可恢复，但运行文件保留。回答质量沿用当前后端，不以新界面验收替代独立质量评测。

## 模型设置（2026-10-24）

顶部“模型配置”：填写API基础地址和密钥，点击“获取模型”，选择服务返回的模型后保存。不支持列表的服务可手动填写ID。现有密钥不回填；同一地址留空保留，变更地址必须填写新密钥。获取列表不生成回答；保存不会自动验证模型生成能力。兼容范围为现有Chat Completions接口，列表中的非文本模型不一定适用。

新增配置检查后共19项测试，运行：`.venv/bin/python -B -m unittest webui.test_server webui.test_config -q`。真实网关可用性与本地研究台连接状态分别判断。产品部署、论文导入边界和本次问题见 [模型设置交接](../docs/WEBUI_MODEL_SETTINGS_2026-10-24.md)。

## 添加PDF（2026-10-24）

打开“论文库”，选择1～5篇PDF（合计20MB、单篇最多200页），按需勾选双栏，点击“添加并入库”。后台完成后列表自动刷新，下一次提问使用新版本。扫描件暂不支持OCR；同内容跳过，批次失败不切换旧库。任务可在刷新后继续查看。

网页库通过`data/webui/library.json`独立选择版本；已不固定为八篇，实验默认值与全局激活指针不变。当前实测9篇1767段。上传文件、状态和新索引不纳入Git。此实现目前在macOS验收，Windows锁机制及全新克隆安装引导待后续补齐。详见 [PDF入库日志](../docs/WEBUI_PDF_IMPORT_2026-10-24.md)。
