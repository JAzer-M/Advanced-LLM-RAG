# 第 6 阶段 A：答案与引用基线检查口径

先建立当前主流程的可审阅基线，本轮暂不修改回答行为。沿用现有 q1–q6；不是新增盲测集，不据此宣称泛化性能。

## 四项独立判断

1. 引用结构：是否使用 `[N]`，编号是否存在。可自动检查；通过不等于语义正确。
2. 引用支撑：拆出实际答案里的重要断言，人工核对其紧邻或所属段落引用。注明 supported / partial / unsupported / contradicted，并保留对应原文与编号；不把“检索到了”当作“引用正确”。
3. 答案内容：检查下列核心事实；补充内容可以省略，但新增错误、无依据因果和过度概括要单独记录。
4. 拒答：q6 应明确现有论文材料不能提供该日期的股价，不猜价格、不把论文中的 NVIDIA 硬件描述当股价依据。正确拒答无需伪造引用。

## 核心事实

- q1：小卷积核堆叠形成更大感受野；引入更多非线性；相对对应的大卷积核减少参数。
- q2：没有循环与卷积；需要注入位置/顺序信息。正弦余弦是补充信息。
- q3：键维度较大时点积幅度增大；softmax 梯度变小；除以键维度平方根进行缩放。矩阵乘法效率是补充信息。
- q4：随机裁剪/平移与水平翻转；RGB 强度的 PCA 扰动；人工增加数据变化以缓解过拟合。
- q5：VGG 主要用 3×3；DCNN 第一层 11×11、第二层 5×5、后三层 3×3。VGG 的 1×1 配置是补充信息，但说“所有层都只有 3×3”需要记为遗漏限定或过度概括。
- q6：针对资料边界明确拒答，不生成股价数值。

严格通过要求核心事实完整、没有实质性错误/无依据新增结论、重要断言有直接来源支撑。语义评价由助手人工审阅，保留依据，不冒充独立专家盲评；不通过词汇命中计算“答案准确率”。

## 执行边界

模型输入仅为问题与主流程生成的上下文；reference_answer、Gold 和本文件不传给模型。复用 q2/q5 既有记录前须核对主流程、证据模块和数据/模型文件哈希，不相同时重新运行。其余问题实际执行 main 的分解、检索、重排序、生成。每题独立保存上下文和原始输出，失败也保留。

本小步仅建立基线并定位下一处具体改进，不同时推进 Single-Agent、LangGraph 或演示应用。
