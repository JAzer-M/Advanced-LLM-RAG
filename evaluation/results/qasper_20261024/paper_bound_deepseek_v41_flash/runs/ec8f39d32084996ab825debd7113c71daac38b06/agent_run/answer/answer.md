专家知识通过“锚点词”(anchor words/锚点变量)的方式融入主题模型：专家指定一组相关性变量(relevance variables),模型在 CorEx 目标函数中加入第二项——即锚点变量 X_i 与隐因子 Y_j 之间的互信息项(对集合 R 中指定的 (i, j) 对)，权重为 β;该项受 information bottleneck 启发，使隐因子在解释数据中多元相关性的同时，也对专家指定的锚点变量保持信息量 [7][13][17]。这样，用户可以利用领域知识引导文档集合的探索，并为 CorEx 学到的隐因子赋予语义 [1],实验表明引入简单的锚点词能提升主题的连贯性和可解释性 [11]。
