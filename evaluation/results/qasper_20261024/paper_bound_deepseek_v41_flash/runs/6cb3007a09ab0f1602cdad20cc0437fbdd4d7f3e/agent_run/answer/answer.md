The paper experiments on several computational models trained and tested on the Offensive Greek Tweet Dataset (OGTD) [1]. For classical machine learning, five models were trained: two SVMs — one with a linear kernel and one with a radial basis function (RBF) kernel — and a linear classifier with Stochastic Gradient Descent (SGDC) learning [11][12], plus two Bayes-based models: Multinomial Naïve Bayes and Bernoulli Naïve Bayes [14]. For deep learning, the first six deep learning models used Greek word embeddings [6], and the sixth deep learning architecture used the available multilingual BERT cased model [9]. The best-performing model was LSTM and GRU with Attention, achieving an F1-macro of 0.89 [5].
