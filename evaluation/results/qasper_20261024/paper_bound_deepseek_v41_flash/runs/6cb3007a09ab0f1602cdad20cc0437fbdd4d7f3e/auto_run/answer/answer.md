The paper experiments on several computational models trained and tested on the OGTD data [1]. These include classical machine learning models—Linear SVM, Naïve Bayes, and Stochastic Gradient Descent (SGD) [2][3][5]—as well as deep learning models, specifically LSTM and GRU with Attention, which achieved the best F1-macro of 0.89 [5]. For the deep learning models, Greek word embeddings trained on a large Greek web corpus were used, with each word represented as a 300-dimensional vector [6]. For the sixth deep learning architecture, they used the available multilingual BERT cased model, since no Greek-specific BERT model was available [9].
