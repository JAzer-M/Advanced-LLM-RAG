The paper characterizes the acceptable language classes as follows. LSTMs "function like counter machines," and convolutional networks are related "to the subregular hierarchy" [3]. Attention is not given a full automaton/language-class characterization in the supplied passages. Instead, attention is shown to add memory by converting the network state into a growing sequence, enabling 2^Θ(n) state complexity [16], and this "exponential state complexity provided by attention enables copying" [17], unlike LSTMs, whose O(nk) complexity "means that it is impossible for LSTMs to copy or reverse long strings" [16]. The exact language class accepted by attention is therefore not established by the supplied passages.
