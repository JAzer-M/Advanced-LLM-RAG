The experiments cover several language sets: POS tagging is performed using Universal Dependencies data for 41 languages [1], with the 41-language list given in a footnote [14]. NER experiments use two datasets: the publicly available CoNLL-2002 and -2003 sets, containing Dutch, Spanish, English, and German, and an in-house dataset with 16 languages using the same CoNLL categories [12]; the 16 languages of the in-house dataset are listed in a footnote as Arabic, Bengali, Czech, German, English, Spanish, French, Hindi, Indonesian, Italian, Japanese, Korean, Portuguese, Russian, Turkish, and Chinese [13].
