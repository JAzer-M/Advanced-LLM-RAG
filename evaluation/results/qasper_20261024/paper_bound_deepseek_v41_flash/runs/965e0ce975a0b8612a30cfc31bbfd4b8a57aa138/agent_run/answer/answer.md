The method has a dedicated mechanism for matching headers: it develops different mechanisms to match a query against each aspect of a table, including headers, cells, and caption [8]; it represents each header as an embedding vector and treats the set of header embeddings as external memory, assigning a probability to each header embedding given the query vector [13]; and it then obtains a query-specific header vector through weighted average [14]. Thus the method relies on the column headings of the table.
