The paper's baselines include XLM (fine-tuned with the English QG data) [8] and PIPELINE (XLM) [9]. PIPELINE (XLM) translates the input Chinese sentences into English first, performs English-English question generation with the XLM model, then translates back to Chinese, using a Transformer translator trained on the MultiUN dataset [13]; a variant, PIPELINE (XLM) with Google Translator, uses Google Translator for the translation step [13]. In the zero-shot English-Chinese question generation experiments, the baselines used are XLM and PIPELINE (XLM) [9].
