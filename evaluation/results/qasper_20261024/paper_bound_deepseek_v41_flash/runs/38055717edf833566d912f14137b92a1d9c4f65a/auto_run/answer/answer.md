The decoder in XNLG is part of a pre-trained sequence-to-sequence model based on Transformer [11]. Both the encoder and decoder support multiple languages, and language tag embeddings are used to distinguish the source and target languages [10]. Given a sentence and its language tag, XNLG encodes the input into vector representations, and by conditioning on those encoding vectors and a specific language tag, the decoder generates the output sequence in the target language [10]. The pre-training objective is designed to represent different languages in a shared space, enabling zero-shot cross-lingual transfer [9].
