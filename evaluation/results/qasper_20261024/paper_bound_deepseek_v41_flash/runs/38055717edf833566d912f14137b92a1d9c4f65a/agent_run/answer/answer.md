The decoder is part of XNLG, a pre-trained sequence-to-sequence model based on Transformer [11]. Both the encoder and decoder support multiple languages, using language tag embeddings to distinguish source and target languages; conditioned on the encoding vectors and a specific target language tag, the decoder generates the output sequence in the target language [10]. The decoder is pre-trained together with the encoder using the 15-language pre-trained XLM to initialize their parameters [7], and pre-training both encoder and decoder (rather than only the encoder) is intended for cross-lingual generation tasks [12].
