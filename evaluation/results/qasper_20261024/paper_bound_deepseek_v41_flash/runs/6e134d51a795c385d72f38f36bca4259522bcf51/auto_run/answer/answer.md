The paper explored three models for generating sentence vectors: averaging the vectors of the words in one sentence, paragraph vectors, and specific word vectors [3]. The first model, AVGWVEC, averages the word vectors in a word sequence, using a word embedding matrix learned by the classical word2vec algorithm [3]. The second model, PARAVEC, trains paragraph vectors using the distributed memory model of paragraph vectors (PV-DM), an extension of word2vec in which the paragraph vectors are held in a matrix D mapping each paragraph to a unique vector [11]. The third model is constructed to improve classification results for a certain category—specifically, identifying the category BAS—by integrating cuewords into the embeddings via BAS-specific word embeddings (BSWE), after which the same averaging scheme as in AVGWVEC is used [8][10].
