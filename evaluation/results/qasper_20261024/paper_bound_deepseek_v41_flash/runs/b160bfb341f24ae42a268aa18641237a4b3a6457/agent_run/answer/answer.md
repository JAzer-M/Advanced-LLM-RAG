They demote the prediction confidences of negative ground-truth domains only when those domains are the highest ranked; this is formulated as the loss Ln = −log(1 − oj) when all other confidences oi (i ≠ j) are ≤ oj, and 0 otherwise, where j is the index of the negative ground-truth domain [15]. The restriction to the highest-ranked case is intended so that the influence of using negative ground-truths is not overwhelming [15].
