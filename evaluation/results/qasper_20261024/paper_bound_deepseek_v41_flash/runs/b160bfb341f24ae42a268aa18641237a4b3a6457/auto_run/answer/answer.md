The amount by which confidences of incorrectly predicted domains are decreased is governed by a negative-feedback loss term, Ln = −log(1 − oj), applied only when the negative ground-truth domain j is top ranked (i.e., when all other domains' confidences oi ≤ oj); otherwise Ln = 0 [18]. This demotion is applied only when the negative ground-truth is the highest, so its influence is not overwhelming [18]. The term is weighted by a hyperparameter β set to 0.00025, which showed the best dev set performance [17].
