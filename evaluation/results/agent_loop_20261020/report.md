## 一、循环与代码入口

[agent.py](../../../agent.py)保留普通函数、字典、列表和中文注释，默认诊断和`--execute-once`行为保留，新增`--max-actions 1～3`。

运行链：规划 → 检查证据 → 检查行动可行性/预算 → 执行工具 → 合并原文 → 再检查；达到answer/stop、无新片段、重复行动无法改选或预算边界时结束。

| 函数/分支 | 解决什么问题 |
| --- | --- |
| `run_diagnostics()`中的while | 每题最多3行动、全批次6次模型请求；循环仅接受1题，落盘保存每步和停止原因 |
| `action_signature()` | 按type/query/source/chunk_id识别重复，reason改写不算新操作 |
| `assess_evidence()` | 传实际工具历史，明确status/证据/supported_part/gap对应关系，按论文目录选择精确source |
| `checked_assessment()` / `revise_assessment()` | 最多一次状态修正或行动改选，原响应保留，新响应仍走原校验；网络失败不自动重试 |
| `shared_question_context()` | 保留原题For/In/Under/On开头、逗号前、不含方法名的公共场景，不添加答案术语 |
| `neighbor_ids()` / `neighbor_fallback()` | 从已有片段的来源、位置、章节判断未读区域，避免围绕同一结果表反复移动 |
| `execute_action()` / `merge_evidence()` | 窗口固定前后各2段，模型query与实际effective_query分开记；原文版本/身份核对与去重保留 |

证据预算仍是32段/24000字符；超限停止，不静默截断或删除旧证据。所有原始范围、来源、原句及状态校验保留。answer仅表示就绪，不调用最终生成器。

## 三、区域兜底为何读到正确原文

只在原建议重复或与此前读取区域重叠超过一半时尝试本地兜底：

- 限定同篇论文、中心必须是已提供给模型的片段。
- 只看原题公共任务词和中心段的章节元数据，至少两个词重合。
- 必须还有未读邻段，候选范围不能再与已读区域重叠超过一半；同任务匹配同分时按文档先后试读。
- 找不到候选时不猜答案。重复行动可使用剩余的一次模型改选机会；仍重复则停止。重叠但没有更好候选时允许原提议继续受其他预算/新增证据规则约束。

本例公共任务词open/domain与“3.1 Open-domain Question Answering”匹配。规则从已有片段中选择763，读到761～765，其中765直接说明报告Exact Match（EM）分数。生产函数没有765、EM或评测答案的条件分支；离线[区域诊断](diagnostics/neighbor_region_probe.json)是在选择后检查返回原文。

章节允许未知，None跳过；相关回归也已补充。这是基于英文原题场景与章节标签的保守启发式，不能宣称覆盖所有问题或论文结构。
