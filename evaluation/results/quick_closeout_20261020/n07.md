# n07: What document representations are precomputed and stored for retrieval or indexing in RAG and ColBERT?

## 回答

当前证据仅能部分回答该问题。

**ColBERT**：ColBERT 设计上将查询与文档之间几乎所有的计算隔离开，主要是为了能够离线预计算文档表示（document representations）[3]；这些表示在生成后会被保存到磁盘，每个维度使用 32 位或 16 位数值存储[2]。

**RAG**：提供的上下文只说明 RAG 将文档索引向量（document index vectors）存储在 CPU 上，使用 FAISS 做最大内积搜索，为全部 Wikipedia 需要约 100 GB 的 CPU 内存[6]；但未具体说明这些文档索引向量由何种表示预计算而来，这部分证据不足。

real main retrieval/rerank and fresh final answer; saved real API decomposition; no regeneration
