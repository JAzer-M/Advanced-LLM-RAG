根据RoFormer论文，其位置编码方法RoPE用旋转矩阵编码绝对位置，同时在自注意力公式中引入显式的相对位置依赖[12][14]。理论上，相对位置通过自注意力中的向量乘积自然表达，绝对位置信息则通过旋转矩阵编码[13]。与以往工作中加性的位置嵌入不同，该方法是乘性的，并通过旋转矩阵乘积自然地纳入相对位置信息，而非修改加性位置编码展开式中的项[15][16]。
