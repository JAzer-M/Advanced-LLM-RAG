# P3新题对照：联网补证有效，名称匹配稳定性未通过

2026-10-22，Asia/Shanghai。用户接受独立新题验收后执行。六题主对照和两题Auto次级验收均已结束；生产代码全程冻结，失败计入原计划分母，没有根据结果调提示或重跑。

本轮观察到两个缺源正例通过读取原论文补齐，但同一标题匹配问题导致一条Agent路径失败、一条Auto路径降级。**本轮实验完成；联网路径稳定性尚未通过，不建议直接进入P4。** 下一步优先修复书目名称与来源修饰词混淆，再作单列开发回归。

## 如何做，为什么这样做

1. 从现有正式题集和旧12/8题排除完全相同问题，选择2本地题、2缺原论文正例、2原论文未报告所问精确数值的反例。外部采用未用于此前调试的RoFormer/FlashAttention；不沿用Mamba开发题。
2. 先保存3716个现有文件哈希、源码/当前文档基线，下载固定版本原文核验Gold，冻结问题、必答/补充规则、失败分母、公开模型选项、脚本和生产源码。避免看到答案再补评分要求。
3. 运行输入文件仅含id/question。Gold、类别、期待路线和参考PDF不传给main；模型必须自己路由、搜索和读取。实际生产库仍是八篇1397段，没有加入这两篇。
4. 六题均独立跑真实main的Agent关闭/开启arXiv；n03/n04另预注册Auto开启，共14路径。各路径真实分解/生成，CPU模型和索引在同进程预加载复用，不复用旧响应。模型请求硬限96，各main的11/14/16上限继续生效。
5. 先用离线替身验证参数、Gold隔离、旧目录保护和调用硬上限，网络/模型调用0；随后才运行真实评测。最后人工核对所有重要断言、实际PDF物理页、引用和拒答，再独立复算实际账本。

题目/评分由同一助手设计和审阅，六题只提供小样本观察；本地题仍使用已有论文和相关概念，不是第三方盲评或统计独立泛化。外部身份明确，不能代表模糊论文定位、多篇合并或普通网页。未重跑旧12/8题、旧h10或旧检索指标。

## Auto次级验收与失败

Auto只预注册两道缺源正例：RoFormer成功，FlashAttention降级，**1/2**，必答点2/5，不能当作六题Auto总体成绩。实际14次模型请求、32875 token（输入31043/输出1832）、2次arXiv GET。

n04-auto主体为`original FlashAttention`，n06-agent-on为`original FlashAttention paper`。模型给出的真实书目标题均正确，但身份校验要求整个主体短语出现在标题中，来源修饰词导致误拒绝。两条路径均在搜索前停止，无arXiv请求；前者degraded保留初检缺口，后者failed无交付，均计分母。

已用现有匹配函数离线复现：带修饰词主体False，方法名FlashAttention与同标题True。这只是诊断，不是修复；不能为了通过而将错误论文的拒绝约束整体放宽。下一步应保留question_quote/need的完整范围，仅在书目身份核对中处理非名称修饰词，并保留错主体/错论文回归。[诊断JSON](failure_diagnosis.json)。

另有一项成本问题：n04-agent-on首份复核的answer_quote只引用[12]，复核却登记[14]，被已有本地校验拒绝。有限修订/再复核额外2请求，最后答案文本未变；所有记录保留，不当作真实事实纠错收益，也不称作HTTP自动重试。

## 实际账本与出处

本轮共**76次chat/76次模型POST，177226 token（输入167220/输出10006）**，全部stop，模型HTTP失败/模型调用失败/usage缺失0；两条路径的运行失败来自本地标题校验。公网实际8次arXiv GET均HTTP200；Gold预核验另2次PDF GET，共10次公开GET。模型judge调用0、自动HTTP重试0；没有核验货币单价或估算金额。96上限未耗尽，未用余额重跑。

模型配置沿用已披露本机反代`http://127.0.0.1:7863/v1`及配置上游、`cn:deepseek-v4.1-flash`，thinking disabled、temperature0、max_tokens4096。用户明确指示执行下一步验收后，具体六题/96上限在运行前说明，真实执行使用同一数据范围（问题、公开论文片段和必要原文）；配置/密钥不进入提示词。旧两题28上限及22请求属于此前实验，没有挪作本轮额度或混合记账。

两篇冻结Gold为[RoFormer v5](https://arxiv.org/abs/2104.09864v5)（14页/44891提取字符）和[FlashAttention v2](https://arxiv.org/abs/2205.14135v2)（34页/108763提取字符）。四次实际PDF读取均与对应Gold哈希相同；全部外部窗口位置/原文及本地登记校验通过，本地证据原顺序/原文保持。实际最大上下文21段、12171字符，仍在32段/24000字符范围；最大字符数和最大段数来自不同路径。重要断言另核对真实物理页，见[人工审阅](manual_review.md)。

CPU资源在同一进程预加载，耗时为交错顺序的单次路径观测，不含冷模型加载，不是并发/P95。全部模型调用真实发生，表中三组请求与token可直接相加得76/177226，不存在共享模型调用需要扣除。
