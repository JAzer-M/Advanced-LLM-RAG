# p4: Self-RAG 的四类 reflection tokens 分别是什么，各负责判断什么？

## 回答

根据提供的证据，SELF-RAG 的四类 reflection tokens 及其判断内容如下：

1. **Retrieve**：输入为 x，输出为 {yes, no, continue}，负责决定何时进行检索（Decides when to retrieve with R）[1]。

2. **ISREL**：输入为 x, d，输出为 {relevant, irrelevant}，判断 d 是否提供对解决 x 有用的信息（d provides useful information to solve x）[1]。

3. **ISSUP**：输入为 x, d, y，输出为 {fully supported, partially supported, no support}，判断 y 中所有值得验证的陈述是否被 d 支持（All of the verification-worthy statement in y is supported by d）[1]。

4. **ISUSE**：输入为 x, y，输出为 {5, 4, 3, 2, 1}，判断 y 是否是对 x 有用的回答（y is a useful response to x）[1]。

表1 说明这四类 reflection tokens 中每一类都用若干 token 表示其输出值 [1]。此外，这些 reflection tokens 分为 retrieval 和 critique 两类，分别指示检索需求和生成质量；表1 中底部三行属于三类 Critique tokens [2][4]。这些 token 用于指示检索需求，或确认输出的相关性、支持性或完整性 [10]。

3 SELF-RAG: LEARNING TO RETRIEVE, GENERATE AND CRITIQUE We introduce Self-Reflective Retrieval-Augmented Generation (SELF-RAG), shown in Figure 1. SELF-RAG is a framework that enhances the quality and factuality of an LLM through retrieval and self-reflection, without sacrificing LLM’s original creativity and versatility. Our end-to-end training lets an LM M generate text informed by retrieved passages, if needed, and criticize the output by learning to generate special tokens.
