# p6: DPR 和 ColBERT 在问题／文档的向量表示以及相关性打分上有什么主要区别？

## 回答

当前证据不足以完整回答该问题中关于“问题／文档向量表示”的所有方面，具体缺失如下：

**DPR 的表示与打分**
- DPR 在运行时使用不同的编码器 EQ(·) 将输入问题映射为 d 维向量，并检索与问题向量最接近的 k 个段落；问题与段落的相似度用二者向量的点积定义：sim(q, p) = EQ(q)⊺EP(p) [5]。
- DPR 擅长语义表示，但可能缺乏表示罕见显著短语的能力 [7]。

**ColBERT 的表示与打分**
- ColBERT 采用 late interaction 架构，用 BERT 分别独立编码查询和文档，然后执行一个廉价但强大的交互步骤来建模细粒度相似度 [8]。
- 在 late interaction 下，q 和 d 被分别编码为两组上下文嵌入，相关性用两组嵌入之间廉价且利于剪枝的计算来评估 [2]。
- ColBERT 具体是找到每个 v ∈ Eq 与 Ed 中向量的最大余弦相似度，并通过求和组合输出；除余弦外也评估平方 L2 距离作为向量相似度度量 [4]。
- ColBERT 编码器将每个查询或文档编码为嵌入的“bag”，采用基于 BERT 的编码器 [9]。
- ColBERT 的第一阶段并发地向 faiss 索引发出 Nq 个向量相似度查询，检索 top-k′（例如 k′ = k/2）匹配 [1]；离线索引时维护每个嵌入到其来源文档的映射，并将所有文档嵌入索引到 faiss [11]。

**可支持的主要区别**
- DPR 将问题与段落各表示为单个向量并以点积打分 [5]；ColBERT 则将查询与文档分别编码为多嵌入集合，并以 MaxSim 式的最大相似度求和（及可选的平方 L2 距离）进行细粒度交互打分 [4][9]。两者都依赖向量相似度检索，但 DPR 的相似度是单向量点积 [5]，ColBERT 是嵌入集合间的最大相似度组合 [4]。

关于两者在“问题／文档向量表示”维度上的其他细节（如具体维度、编码器层数等）在给定上下文中证据不足，无法进一步比较。
