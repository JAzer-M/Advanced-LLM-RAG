They use a **word2vec** (Mikolov et al., 2013) word embedding model trained specifically on financial data.

They trained this word2vec model on a set of 189,206 financial articles containing 161,877,425 tokens, manually downloaded from Factiva, with articles from sources including the Financial Times relating to United States companies [4]. They report a number of different evaluations using this finance-specific word embedding model [2].
