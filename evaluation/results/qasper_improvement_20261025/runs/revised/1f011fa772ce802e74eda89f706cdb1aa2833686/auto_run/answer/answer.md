The paper uses a rich set of textual features: theme-based features (modeling emotions, stance, and other changes per theme), NLI-style writing features (bag of stopwords, POS tags, syntactic dependency relations), and profiling features.

The approach is "mainly based on textual features which utilize thematic information, and profiling features to identify the accounts from their way of writing tweets" [2]. Textual features are modeled independently for each theme to capture emotional, stance, and other changes in users' tweets [1]. Theme-based features include emotions, computed with the NRC emotions lexicon (~14K words labeled with Plutchik's eight emotions), motivated by IRA efforts to seed discord (e.g., fear-spreading behavior) [9]. For detecting writing-style patterns, they use NLI features consisting of a bag of stopwords, part-of-speech tags (POS), and syntactic dependency relations (DEPREL) [6]. These are combined with surface text features, and the extracted themes boosted performance when coupled with them [8].
