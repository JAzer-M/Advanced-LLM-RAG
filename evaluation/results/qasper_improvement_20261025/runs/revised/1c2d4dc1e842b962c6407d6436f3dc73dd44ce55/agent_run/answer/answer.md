The four learning strategies investigated are: ModelI Base, ModelII BERT, ModelIII Tag, and ModelIV Meta [6].

The paper states that it investigates four learning strategies and examines their abilities to deal with the domain shift problem [1]. All four strategy names are listed in the results table of the experiments on the MULTI-SUM dataset [6]. Specifically: ModelI Base is a simple multi-domain learning model in which all domains are aggregated and used to train a set of shared parameters, with domains not explicitly informed of their differences [14]; ModelII BERT is a BERT-based strategy, and its smaller ∆R compared with ModelI Base suggests BERT shows some domain generalization ability within MULTI-SUM [8]; and ModelIV Meta uses meta-learning to bridge the communication gap between different domains when updating shared parameters [9]. The passages provided only name ModelIII Tag [6] and do not describe its mechanism further.
