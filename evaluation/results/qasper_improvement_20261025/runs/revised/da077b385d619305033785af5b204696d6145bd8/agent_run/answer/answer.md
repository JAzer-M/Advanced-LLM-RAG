Yes, the query-bag matching model uses a neural network. Its core component hCNN is a CNN-based matching model: the query q and the i-th question b_i in the bag are fed into a CNN respectively, and a cross-attention matrix M_i is fed into another CNN to obtain the interaction representation [4]. In addition, an hCNN is used to model the relationship between the user query and the new "question" b_r (built via TF-IDF) to obtain the matching representation r_r used to predict the query-bag matching degree [5].
