Weighing between statistical models is done via an overlap-based consensus scheme: for each of the g models, a sentence's cumulative weight cWeight(si) = Σⱼ₌₁ᵍ Wᵢ B(j, si), where B(j, si) is 1 if the sentence appears in the jth model's summary and 0 otherwise, with weights assigned without training as Wᵢ = 1/g (equal weights) [5][6].

For the multi-document/domain-specific setting, weights are instead fine-tuned with supervision: using a training set of domain-specific documents with gold-standard human summaries, each model's weight is assigned from its F1-score/F-measure per document (Wi = f(j,i)·... with f(j,i) the F1-score of the jth model on the ith document), and a supervised learning algorithm captures the mean performance of the models over training data to fine-tune the cumulative summary [2][7].
