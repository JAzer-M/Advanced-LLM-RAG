The experiments use two datasets: AliMe and Quora [1].

The AliMe dataset was collected from the AliMe intelligent assistant system in E-commerce, with 8,004 query-bag pairs gathered [1]. The Quora dataset is based on the public Quora dataset originally released for duplicated question detection, containing 400,000 question pairs labeled by whether they ask the same question; one question in the bag serves as the query while the other questions form the bag, yielding 20,354 training, 2,000 validation, and 10,000 test cases [1][7][8].
