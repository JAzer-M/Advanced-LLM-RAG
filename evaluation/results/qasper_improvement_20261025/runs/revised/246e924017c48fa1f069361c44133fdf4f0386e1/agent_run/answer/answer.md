The selected sharing layer is trained jointly with the whole model via a global loss function: given the predictions of all tasks (stance detection and fake news detection), the model minimizes the cross-entropy between prediction and true distribution for all tasks, with each task weighted by λi (N = 2, and the fake news detection task is given more weight λ) [2][14].

The model is a sifted multi-task learning framework on a shared-private architecture that jointly trains stance detection and fake news detection, filtering the shared layer's outputs through a selected sharing layer [2]. The selected sharing layer's outputs (SSLi) are concatenated with task-private features Hi and fed to a softmax output layer for each task's prediction [4], and this whole model is then driven by the global cross-entropy loss [14]. Its internal parameters, such as Wfake and bfake of the gated sharing cell, are trainable parameters [1]. The passages do not specify a separate training procedure or learning details exclusive to the selected sharing layer beyond this joint global-loss training.
