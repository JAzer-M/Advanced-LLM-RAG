Description length here is the total code length needed to encode the verb phrases under a pattern assignment: given verb phrases, the goal is to find the best assignment function f that minimizes the code length of the phrases [1]. This is formalized via minimum description length (MDL), which is based on the idea of data compression — verb patterns are treated as a compressed representation of verb phrases, so that if the pattern assignment provides a compact description of phrases, it captures the underlying verb semantics well [1]. Concretely, the description length of an assignment f is computed by summing up all n phrases' code lengths [2], and the model seeks the f minimizing this length within the MDL framework [8][11].
