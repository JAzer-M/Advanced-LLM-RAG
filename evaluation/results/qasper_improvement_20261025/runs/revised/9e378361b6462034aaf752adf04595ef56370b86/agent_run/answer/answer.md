The paper used AutoSlog-TS embedded in a bootstrapping framework: initial patterns were learned from labeled training data, then high-precision patterns were matched against unannotated posts to acquire new patterns, with the process repeating over four iterations.

Specifically, the authors use AutoSlog-TS (Riloff, 1996) to extract linguistic expressions from annotated texts, and because the IAC contains many unannotated debate posts, they embed AutoSlog-TS in a bootstrapping framework to learn additional patterns from the unannotated texts [8], [3]. Initially, the labeled training data is given to AutoSlog-TS, which generates patterns and associated statistics [3]. The high-precision patterns are then matched against the 11,561 unannotated posts from 4forums.com; in each bootstrapping round, posts matching at least 3 patterns associated with a given class are assigned to that class [5]. A Bootstrapped Data Balancer then randomly selects a balanced subset of the newly classified posts to maintain the same proportion of FACTUAL vs. FEELING documents, and these new documents are added to the labeled set so the bootstrapping process repeats, using the same threshold values to select new high-precision patterns across iterations [6]. The algorithm was run for four iterations [9], with new patterns added after each round [7].
