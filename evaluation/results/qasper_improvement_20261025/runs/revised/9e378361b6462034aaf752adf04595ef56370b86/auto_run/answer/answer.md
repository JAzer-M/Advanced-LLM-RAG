The paper used AutoSlog-TS embedded in a bootstrapping framework, starting with patterns from annotated posts, then iteratively using high-precision patterns to classify unannotated posts and learn new patterns.

AutoSlog-TS was first given the labeled training data to generate patterns and associated statistics [3]. The resulting high-precision patterns were then matched against 11,561 unannotated posts from 4forums.com, and posts matching at least 3 patterns associated with a given class were assigned to that class [5]. The Bootstrapped Data Balancer randomly selected a balanced subset of newly classified posts to maintain the same proportion of FACTUAL vs. FEELING documents, added them to the labeled set, and the process repeated for four iterations using the same threshold values for selecting new high-precision patterns [6][9]. This produced a growing set of patterns (from 1,874 at Iteration 0 to 5,830 after Iteration 4) [7].
