The paper uses the Japanese-English (Ja-En) ASPEC dataset and the WMT English-German (En-De) dataset.

The primary corpus is the Japanese-English (Ja-En) ASPEC dataset, with a subset of 500K sentence pairs selected to train the models [1]. The method is also applied to the WMT dataset for English-German (En-De), using news-test2014 as a development set and news-test2015 and news-test2016 as test sets [2].
