The model is a neural architecture that combines sentence-level attention with a document-level context encoder to learn context-aware representations for fine-grained entity typing (Figure 1) [4], [5].

Specifically, the task is formulated as multi-label classification, and the general model uses logistic regression given a type embedding vector wt and a featurizer ϕ(e, x) to model the probability of entity e being assigned type t [9], [10]. For sentence-level context, the feature representation is a weighted sum of hidden states, using dot-product attention (Luong et al., 2015) that computes attention based on the alignment between the entity and its context — unlike the self-attention of Shimaoka et al. (2017), which only considers the context [11], [8]. The document-level context encoder is a multi-layer perceptron, gd(xd) = relu(Wd1 tanh(Wd2 DM(xd))), where DM is a pretrained distributed memory model (Le and Mikolov, 2014) that converts the document-level context into a distributed representation [8]. Overall, the architecture leverages both document-level and sentence-level semantic context to learn more context-aware representations than prior work [4], [5], [7].
