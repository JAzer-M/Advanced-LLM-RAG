The model is a neural architecture for fine-grained entity typing that treats the task as multi-label classification using logistic regression over type embeddings, with a featurizer combining sentence- and document-level context encoders plus attention [9][10][4].

Given an entity e and context x, the general model uses logistic regression with a type embedding vector wt to model the probability that e is assigned type t, learning a type embedding matrix [10]. The task is framed as multi-label classification, where each entity is assigned a set of types from a fine-grained type set [9]. The featurizer combines a sentence-level context encoder (two separate bi-directional RNNs for context on each side of the entity mention) with a weighted-sum attention over hidden states using dot-product attention based on entity–context alignment, and a document-level context encoder that is a multi-layer perceptron over a pretrained distributed memory model (DM) representation of the document [11][8]. This design leverages both document- and sentence-level information, which is more context than prior work [4][5].
