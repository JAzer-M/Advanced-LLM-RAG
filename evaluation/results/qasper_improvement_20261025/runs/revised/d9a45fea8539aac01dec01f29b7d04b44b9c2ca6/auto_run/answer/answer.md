The rest of the multi-task learning setup uses a shared-private model architecture, organized as a 4-level hierarchical structure.

The paper proposes a sifted multi-task learning method on the ground of a shared-private model to jointly train stance detection and fake news detection, filtering the original outputs of the shared layer via a selected sharing layer, and the model consists of a 4-level hierarchical structure [4]. The shared-private model divides the features of different tasks into private and shared spaces, where shared features serve as supplementary features for different tasks [7]. Because the shared space can mix task-relevant features that introduce noise, the selected sharing layer uses a single gate mechanism to filter useless shared features and an attention mechanism (a transformer encoder cell weighting shared features with task-specific input embeddings) to focus on features helpful to the target tasks [2][3][10]. The output layer applies a softmax over the concatenation of each task's private features and its selected-sharing-layer outputs to produce the classification [8].
