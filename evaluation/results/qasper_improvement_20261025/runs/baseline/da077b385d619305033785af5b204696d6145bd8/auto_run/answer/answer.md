Yes, the query-bag matching model uses neural networks. The paper's model (QBM) includes a mutual coverage component based on the cross-attention matrix of the query-bag pair [8], and it employs an hCNN component, a CNN-based matching model in which the query and a question in the bag are fed into a CNN respectively, with the cross-attention matrix fed into another CNN to obtain the interaction representation [5]. The introduction also notes that researchers have adopted deep neural networks to model matching relationships in related text matching work [1].
