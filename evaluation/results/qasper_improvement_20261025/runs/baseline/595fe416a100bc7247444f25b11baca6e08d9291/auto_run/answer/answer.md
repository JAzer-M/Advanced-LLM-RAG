The paper's profiling features are text-based: they are used to identify accounts from their **way of writing tweets**, and are coupled with thematic and textual features to enhance the model's performance [1]. A specific example is the **Native Language Identification (NLI)** feature, which aims to detect IRA trolls by identifying their writing style in English tweets, exploiting that English tweets by non-native speakers exhibit different syntactic patterns [5]. The "Profiling Features" are also reported as an independent feature set in the classification results (separate from Network Features, theme-based features, etc.) [7].

Note that these profiling features should not be confused with the account metadata available in the Twitter-provided IRA dataset (profile description, account creation date, follower/followee counts, location, and account language); that dataset contains limited account details, and only the follower and followee counts were additionally used as a "Network Features" baseline [3].
