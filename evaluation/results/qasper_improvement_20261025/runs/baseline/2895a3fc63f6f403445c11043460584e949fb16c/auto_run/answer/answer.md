In this paper, description length refers to the code length of phrases under a pattern assignment: MDL is based on the idea of data compression, and verb patterns are regarded as a compressed representation of verb phrases [4]. Intuitively, if the pattern assignment provides a compact description of phrases, it captures the underlying verb semantics well, so the goal is to find the best assignment function f that minimizes the code length of phrases [4]. The description length L(f) is computed for an assignment f by summing up all n phrases' code lengths [9], and the best assignment f also lets them compute the pattern distribution P(A) = P(a|p)P(p) over phrases of the verb of interest [10]. The model uses MDL as the basic framework to reconcile the two objectives of generality and specificity of verb patterns [2].
