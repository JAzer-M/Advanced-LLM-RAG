The patterns correlated with emotional (FEELING) arguments include: expressions with adjectives and active voice verb phrases [3]; patterns based on the speaker's own beliefs or claims, or involving assessments/evaluations of the arguments [4]; and NP Prep patterns with the preposition "for," which are substantially more common in the FEEL class and commonly express advocacy (e.g., "demand for") or refer to affected population groups (e.g., "treatment for") [6].
