The MTL model's hyperparameters: word embedding and position embedding sizes are 200 and 100; in the transformer encoder, the number of attention heads is 6 (11) with 2 blocks, and multi-head attention dropout is 0.7; the mini-batch size is 64, the initial learning rate is 0.001, the dropout rate is 0.3, and λ is 0.6 for the fake news detection task [21]. All hyperparameters were tuned on the validation dataset, achieving the best performance via a small grid search [15].
