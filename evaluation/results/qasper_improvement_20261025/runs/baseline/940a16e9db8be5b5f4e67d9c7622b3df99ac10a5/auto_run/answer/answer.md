The paper extends the conventional definition of "domain" in text summarization from document categories to data sources: it demonstrates that news publications can cause data distribution differences, meaning news publications themselves can be defined as domains [3]. Previously, domains in summarization were treated as document categories, but only DUC and NYT are annotated with such categories, and DUC is designed only for competition testing [10][11]. Based on this, the authors build a multi-domain testbed for summarization requiring training and evaluation across a set of domains [1].
