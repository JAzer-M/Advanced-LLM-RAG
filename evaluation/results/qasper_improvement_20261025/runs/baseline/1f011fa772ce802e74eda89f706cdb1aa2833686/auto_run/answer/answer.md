The paper uses a rich set of textual features to identify IRA trolls, relying only on the text of their tweets [8]. These features are grounded in thematic information, which the authors deduced in an unsupervised way; coupling thematic features with other textual features enhanced the model's performance [1]. Based on the extracted themes (e.g., supporting Trump, attacking Hillary), they model textual features independently for each theme to capture emotional, stance, and other changes in users' tweets [3]. The features also include Native Language Identification (NLI), inspired by earlier work on identifying the native language of essay writers, which detects IRA trolls by their way of writing English tweets—non-native English speakers' tweets show different syntactic patterns [4]. Profiling features that identify accounts from their way of writing tweets are also mentioned as part of the text-based approach [1], and the NLI features were reported to be very effective [9].
