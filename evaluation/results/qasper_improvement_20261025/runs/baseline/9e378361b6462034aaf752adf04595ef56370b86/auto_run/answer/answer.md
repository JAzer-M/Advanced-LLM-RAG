The paper embeds the AutoSlog-TS pattern learner in a bootstrapping framework to learn additional patterns from the large pool of unannotated debate forum posts in the IAC dataset [7]. The process works as follows: the labeled training data is first given to AutoSlog-TS, which generates patterns and associated statistics [5]. The resulting high-precision patterns are then used to identify more FACTUAL and FEELING texts from 11,561 unannotated posts from 4forums.com, where posts that match at least 3 patterns associated with a given class are assigned to that class [6]. A Bootstrapped Data Balancer then randomly selects a balanced subset of the newly classified posts to maintain the same proportion of FACTUAL vs. FEELING documents throughout the process, these new documents are added to the labeled set, and the bootstrapping process repeats using the same threshold values to select new high-precision patterns [8].
