The paper does not allow identifying the exact best combination unambiguously: it reports that mixing semantic and statistical models improves over stand-alone models, with the InferSent-based summarizer performing "exceptionally well" [1][3], and the highest combination ROUGE-2 scores in Table 2 are 0.03986 and 0.04003 [12]. However, the table's model-indicator markers (A→Jaccard/Cosine, B→TextRank, C→TFIDF, D→WordNet, E→Glove-vec, F→InferSent [12]) are garbled, so which exact statistical model paired with InferSent (or another semantic model) achieved these top scores cannot be established from the provided passages. What can be said is that combinations involving TF/IDF and Jaccard/Cosine similarity matrices offered nearly the same results, and the InferSent-based summarizer was the standout semantic component [1].
