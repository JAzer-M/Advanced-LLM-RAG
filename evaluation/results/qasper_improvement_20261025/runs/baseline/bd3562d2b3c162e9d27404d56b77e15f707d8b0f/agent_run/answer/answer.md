该论文使用了主办方采用的三种评估指标 [3]：

1. **Metric 1**：原始指标——加权余弦相似度（weighted cosine similarity），用于评估最终版本结果（排名5th）[3]。
2. **Metric 2**：公式1（evaluation deadline 后更改的指标），第一版结果基于该指标（排名4th）。它对符号相反的预测给予 -1 分、符号相同的给予 +1 分的奖惩 [5][2]。
3. **Metric 3**：主办方在 Cortis et al. (2017) 中给出的公式，第二版结果基于该指标（排名5th）[5]。

结果表中同时报告了三种指标下的分数（如 ELSTM：73.20 / 61.98 / 69.24）[6]。
