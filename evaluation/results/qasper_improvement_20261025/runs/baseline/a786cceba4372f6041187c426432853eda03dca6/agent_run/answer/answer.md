The state of the art is defined by this paper's own methodology: on the “IRA Russian Troll” dataset, it improves over the previous state-of-the-art in the supervised learning scenario, raising classification accuracy by more than 5 percentage points [6][11]. The paper's approach uses embeddings built on the user-to-user mention graph, the user-to-hashtag mention graph, and the text of the trolls' tweets, combined with the community structure of the network represented as a graph [11][6]. It also provides a compelling case for a second, realistic unsupervised scenario (predicting trolls' political roles—left, news feed, right—without labels), which had not been explored in the literature before [6][2]; in that scenario, even when hiding the labels from the ML algorithm, 78.5% of correct labels can be recovered [2].
