The paper weights the different models by training on a domain-specific corpus: for a set of u domain-specific documents with gold-standard (human-composed) summaries, they fine-tune weights Wi for each model i using the F1-score (F-measure) as the factor [2][11]. Specifically, each model's weight is assigned as Wi = u·f(j,i) / Σ f(j,i), where f(j,i) is the F1-score of the jth model on the ith document [2]. They then compute a cWeight for each sentence using the g models and formulate a cumulative summary capturing the consensus of the different models [2][6]. They describe this as a supervised learning algorithm that captures the mean performances of different models over training data to fine-tune the summary [2]. The weights are stored along with sense vectors for future reference; for single-document summarization, the sense vector of the new document is computed and the weights of the nearest stored vector are used [1]. The motivation is that there is significant variation in model choices among different fields [4].
