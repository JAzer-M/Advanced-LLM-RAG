They weigh the models supervisedly: using a training set of u domain-specific documents with gold-standard/human-composed summaries, they fine-tune weights Wi for the g different models, taking the F1-score/F-measure as the factor [11]. Concretely, each model's weight is assigned via Wi = (Σ_{j=1}^{u} f(j,i)) / u, where f(j,i) denotes the F1-score of the jth model on the ith document [2]. The weighted outputs of the models are then combined into a cWeight per sentence, forming a cumulative summary that captures the consensus of different models, using a supervised learning algorithm to capture the mean performances over the training data [2].
