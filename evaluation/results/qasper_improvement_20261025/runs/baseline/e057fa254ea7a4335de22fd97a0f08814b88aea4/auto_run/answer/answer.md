The model is a neural architecture for fine-grained entity typing, treated as multi-label classification where each entity e in text x is assigned a set of types from a fine-grained type set [2]. The featurizer contains three encoders that encode the entity e and its context x into feature vectors, considering both sentence-level context xs and document-level context xd — in contrast to prior work which mainly takes only sentence-level context, although document-level context has also been exploited in some earlier works [11]. The context feature representation is computed via dot-product attention as a weighted sum of hidden states, where attention is based on the alignment between the entity and its context [9]. The architecture learns a distributional semantic representation leveraging both document and sentence level information [3], and additionally uses adaptive classification thresholds to boost performance [1].
