# q2: Why does the Transformer use positional encoding?

## 回答

The Transformer uses positional encoding because the model contains no recurrence and no convolution, so it must inject some information about the relative or absolute position of the tokens in the sequence in order for the model to make use of sequence order [1]. To this end, positional encodings are added to the input embeddings at the bottoms of the encoder and decoder stacks; they have the same dimension dmodel as the embeddings so the two can be summed [1][10]. The specific encodings used are sine and cosine functions of different frequencies, where each dimension of the positional encoding corresponds to a sinusoid and the wavelengths form a geometric progression from 2π to 10000 · 2π [4]. As a model variation, replacing the sinusoidal positional encoding with learned positional embeddings produced nearly identical results to the base model [6].
