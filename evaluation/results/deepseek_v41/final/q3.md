# q3: Why does the Transformer use scaled dot-product attention?

## 回答

The Transformer uses scaled dot-product attention because, for large values of dk, the dot products grow large in magnitude, pushing the softmax function into regions with extremely small gradients, so the dot products are scaled by 1/√dk to counteract this effect [2]. Among attention mechanisms, dot-product attention is much faster and more space-efficient in practice than additive attention—despite the two being similar in theoretical complexity—because it can be implemented using highly optimized matrix multiplication code; dot-product attention is identical to their algorithm except for the scaling factor of 1/√dk, whereas additive attention computes the compatibility function using a feed-forward network with a single hidden layer [4]. The sources do not further justify why scaling is preferred beyond these stated mechanisms.
