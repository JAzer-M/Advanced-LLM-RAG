# q4: How does the DCNN paper use data augmentation to reduce overfitting?

## 原始答案

The DCNN paper employs two distinct forms of data augmentation to reduce overfitting, both of which allow transformed images to be produced from the original images with very little computation, so the transformed images do not need to be stored on disk [1]. The first form consists of generating image translations and horizontal reflections [3]. Specifically, this is done by extracting random 224 × 224 patches (and their horizontal reflections) from the 256 × 256 images and training the network on these extracted patches, which increases the size of the training set by a factor of 2048 [6]. Without this scheme, the network suffers from substantial overfitting, which would have forced the authors to use much smaller networks [6]. The second form of data augmentation consists of altering the intensities of the RGB channels in training images, specifically by performing PCA on the set of RGB pixel values throughout the ImageNet training set [4]. The transformed images are generated in Python code on the CPU while the GPU is training on the previous batch of images, making these data augmentation schemes, in effect, computationally free [3].
