# q5: How do VGG and DCNN differ in their use of convolutional filter sizes?

## 回答

VGG uses very small 3 × 3 convolution filters throughout its convolutional layers, which the authors describe as the smallest size to capture left/right, up/down, center [10], and state that increasing depth is feasible due to the use of these very small (3 × 3) filters in all layers [5]. One VGG configuration also uses 1 × 1 convolution filters, viewed as a linear transformation of the input channels [4].

DCNN, by contrast, uses larger and varying spatial filter sizes across its convolutional layers: the first layer uses 96 kernels of size 11 × 11 × 3 [9], the second uses 256 kernels of size 5 × 5 × 48 [3], and the third, fourth, and fifth layers use 3 × 3 spatial kernels (384 kernels of size 3 × 3 × 256, 384 kernels of size 3 × 3 × 192, and 256 kernels of size 3 × 3 × 192, respectively) [6].
