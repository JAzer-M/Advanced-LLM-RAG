# n08: metadata-only replay

Self-RAG decodes a retrieval token for every x and preceding generation y<t to evaluate the utility of retrieval; if retrieval is not required, the model predicts the next output segment as a standard LM [1]. CRAG quantifies a relevance score into three confidence degrees—Correct, Incorrect, Ambiguous—and triggers corresponding actions [2]. If Correct is triggered, retrieved documents are refined into more precise knowledge strips via knowledge decomposition, filter, and recomposition [2]. If Incorrect is triggered, the retrieved documents are discarded [2]; web searches are resorted to and regarded as complementary knowledge sources for corrections [3]. When it cannot confidently make a correct or incorrect judgment, an Ambiguous action combining both is triggered [3].
