2026-10-23（Asia/Shanghai）。用户希望先试一个小版本，看看界面效果。本轮完成PaperLens本地工作台，已在Codex浏览器打开；原型位于`ui_prototype/`，没有修改现有生产后端或安装新依赖，没有注册/发布云端站点。

启动方式：[说明](../../../ui_prototype/README.md)。本机地址：[http://127.0.0.1:8848](http://127.0.0.1:8848)。

## 可以实际体验

- 问题输入、RAG/Auto/Agent模式选择、默认关闭的联网开关。
- 答案、引用原文及页码、引用定位与片段展开、全部证据、运行过程、token和耗时。
- 三个明确标注为历史记录的真实案例：Transformer本地回答、FlashAttention联网补证据、搜索超时后的未核实说明；回放不调用模型。
- 八篇、1397段的真实知识库目录，固定RAG显式使用八篇库，激活指针不变。
- 宽屏工作台与窄窗口布局；窄窗口实际检查了知识库入口、模式、提问、案例及答案显示。

页面使用原生HTML/CSS/JS，后端是普通WSGI函数和内存任务字典。点击实时运行后才启动独立问答进程，调用原`main()`，保留现有调用预算、来源/引文校验与失败状态。浏览器只接收展示白名单，不接收配置、凭证、模型提示词或绝对本机路径。一个时间只运行一题，任务运行时禁用重复提交。

浏览器实际检查：

1. 切换正常/来源不可用历史案例，历史状态、日期与“原运行成本”明确可见，当前回放不计新模型请求。
2. 点击FlashAttention引用12后定位、展开第1页原文；外部来源标题取自该次真实搜索题录，原文不改写。

## 一次真实网页问答

问题：According to VGG, what convolution stride and input padding are used for its 3x3 convolution layers?

请求前保存[输入与源码协议](live_check_protocol.json)。只跑一条已知开发题，固定RAG默认路径至多3模型请求，arXiv关闭；没有调提示重跑或把旧答案传给模型。

| 实测 | 结果 |
| --- | --- |
| 状态 | completed / not_reviewed，RAG只做引用结构检查 |
| 回答 | 步长1像素；3×3卷积的padding为1像素，以保持空间分辨率 |
| 引用 | [1] VGG.pdf，第2页；人工核对原文明确写出stride 1 pixel、padding 1 pixel for 3×3 conv |
| 模型 | 2次实际调用，输入2733/输出72/总2805 token，失败和usage缺失0 |
| 耗时 | 约15.3秒，含该问答进程加载资源的单次值，非P95 |
| arXiv / 本地自动重试 | 0 / 0 |

这是界面到真实后端的工程冒烟，不是独立新题质量分数。本轮只实际新跑RAG；Agent/Auto入口已接既有后端，其他模式的真实网页调用未重复付费跑。核对见[摘要与原文](smoke_summary.json)、[完整返回](live_result.json)、[实时页面截图](live_answer.jpg)。原运行记录保存在`logs/ui_prototype/20261023T025350Z_a64353df/`。
