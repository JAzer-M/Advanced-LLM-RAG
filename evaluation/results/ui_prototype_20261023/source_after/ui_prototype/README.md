# PaperLens 本地问答原型

这是P4的小型试验版，用来体验“提问 → 回答 → 引用原文 → 运行记录”。原型单独放置，现有生产后端没有改动；无需安装前端框架或新Python依赖。

在项目根目录启动：

```bash
.venv/bin/python ui_prototype/app.py
```

打开 [http://127.0.0.1:8848](http://127.0.0.1:8848)。服务只监听本机，关闭终端或按Ctrl+C即可停止。

## 可以体验什么

- 三个真实历史案例：Transformer本地回答、FlashAttention联网补证据、外部来源不可用。回放不调用模型，历史状态与成本明确标注。
- 实时提问：RAG / Auto / Agent三模式，直接调用现有`main()`；固定使用八篇、1397段知识库，不更改激活指针。
- 联网开关默认关闭；RAG只使用本地库，Agent/Auto沿用原联网与模型调用预算。
- 点击引用编号定位原文、展开片段、切换全部证据、查看实际运行过程和token用量。
- 知识库目录、答案复制，以及适配侧边窄窗口的布局。

实时提问会使用现有私有API配置，可能产生模型费用。配置和凭证只由Python后端读取，不发送到页面；启动、看案例、看原文和查看知识库均不调用模型。首次提问会加载本地模型。

## 实现与边界

| 文件 | 作用 |
| --- | --- |
| `app.py` | 标准库WSGI服务、只读案例接口、内存任务、独立问答进程与展示字段筛选 |
| `index.html` / `style.css` / `app.js` | 原生网页、布局及交互，无构建步骤 |

同一时刻只运行一个问题；模型运行放在独立进程，页面可以持续显示等待状态。实时记录保存在`logs/ui_prototype/`的新目录；Agent/Auto另保留原后端的完整pipeline账本。浏览器刷新恢复默认历史案例，不自动重新调用模型。

这是本地单用户原型，尚未做安装包、多人访问、持久会话、上传论文和正式发布。arXiv限流/超时等后端边界沿用现有处理，不在界面中伪装为成功。[本轮实现与验收](../evaluation/results/ui_prototype_20261023/report.md)
