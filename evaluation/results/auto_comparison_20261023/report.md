# Auto比较题与网页访问修复（2026-10-23）

用户问题：`what is the difference between VGG and RAG?`。原网页记录为101.85秒、8模型请求、28092 token，答案偏成VGG不同配置和RAG不同形式，并声称没有直接比较表述就不能概括差异。

最终同题真实浏览器→独立进程→main Auto为30.98秒、2模型请求、4037 token，直接比较视觉识别与语言生成及其机制。耗时减少约69.6%。这是已暴露开发题的前后验证，不能当成独立准确率或P95。核心比较通过原文核对；附带训练句的引用仍不完整，不宣称全文严格引用全通过。

## 根因与选择

1. 原RAG提示强调逐句直接支持，模型把“没有跨论文直接比较句”误当作比较所需事实缺失。初稿因此触发Auto升级。
2. `agent.isolate_need`把共享比较投影成`difference between vgg?`和`difference between rag?`，后续检查、搜索和复核沿错误需求运行。
3. 原模型请求合计29.549秒，完整用户运行101.85秒。用其保存的分解结果、真实CPU模型、无新模型请求的本地初检重放为65.028秒，其中规则补查40.130秒；主要延迟来自多次BGE重排和补查。单独启用分数缓存后，同样初检50.712秒，原10个选中ID不变。这两次只衡量缓存，尚未启用概览快速路径。
4. 正确比较后的“没有同任务性能对比”等可选说明，仍被宽泛正则识别为核心缺口。真实复验保留了几种措辞的失败，最终按句子主题而非单一固定措辞处理。
5. 网页打不开时，8848端口无监听；重新启动后HTTP200。具体服务此前如何停止没有证据，不能断言是用户关了终端。

## 实际改动与优先级

- P1：比较需求改成每方的事实描述，保留明确比较方面和原审计引文；非对称数据集/条件仍隔离。RAG、Agent生成和复核允许根据双方各自原文归纳差异，仍禁止无依据的因果关系和性能排序。
- P1：对简单英语`what is/are the difference(s) between ...`概览题，识别恰好两篇本地主论文，且双方开头确有摘要标记后，追加每篇最多4段开头原文。原初选和编号保留，原文不改写。本题仍初选10段，登记表19段。
- P2：上述概览在默认自动补查时先生成，不重复按来源补查；有具体方面、没有摘要、其他问法或显式`complete_evidence=True`继续原路径。两轮上限和普通题型预算不改。模型有真实核心缺口时仍可升级Agent。
- P2：同一请求用普通字典复用相同模型、查询和原文的BGE分数，不缓存模型回答、不跨问题共享事实，不减少候选120或最终Top-10。普通检索和Agent/联网预算不改。
- P2：仅对未要求定量/实验比较的上述概览，忽略已有引文事实之后的可选性能/直接对比说明；缺少架构、机制、用途等核心事实、开头拒答或明确性能提问仍升级。该门控是启发式，不是语义正确性证明。
- 网页：新增Mac双击启动文件`ui_prototype/start.command`；已有服务不重复启动，不安装后台服务。普通补查失败与外部来源不可用分开显示。

生产修改限`main.py`、`agent.py`、`src/query_decomposer.py`、`src/agent_answer.py`、`src/reranker.py`、`src/evidence_gap.py`，以及一行UI状态文案。原普通函数/字典/列表结构保留，无新框架或依赖。测试增加17项，原两处替身补齐新增可选参数。

## 验证及全部真实开发成本

先保留4338份既有文件哈希，初始错误需求/过度调用检查为红；新增比较意图与缓存回归也先失败。早期缓存测试夹具缺section、旧入口测试替身缺query参数的错误及原日志均保留，修改夹具接口后不放松原断言。

最终331项离线测试通过，失败/错误/跳过/网络尝试0。覆盖真实问题的需求绑定、非对称范围、预算、引文检查、缓存结果/候选/轮数一致性、摘要条件、显式强制补查、可选说明不误升级及实际核心缺口仍升级。四份真实初稿按最终门控本地检查均不再误升级，无新增API；最终又从浏览器实际生成新响应确认。初始与中间测试、源码快照和所有失败均保留。

## 原文核对与残留

最终[12]/VGG第1页支持图像识别任务，[13]/第1页支持3×3和16–19层；[18]、[19]/RAG第1页支持用于语言生成的参数/非参数记忆及预训练seq2seq、神经检索器和Wikipedia索引。所有19条登记原文的chunk_id/来源/页码/文字均与八篇知识库一致。

**残留：** 最终附带“生成器与检索器联合微调”这句的[19]只覆盖方法定义，未完整覆盖训练细节。实际支持位于本轮已提供但该句未引用的[7]/RAG第2页。它不改变主要比较结论，也不属于编造的事实；仍是引用覆盖瑕疵，下一步优先精简未要求训练背景或提高局部引用检查。保留原始输出，没有手动美化成模型原生全通过。`answer_status=not_reviewed`，只通过引用结构检查和本次核心原文核对。

当前约31秒仍含独立进程导入、CPU模型加载与474对左右的初检重排，尚未做常驻模型、并发、流式生成或更换重排模型。快速路径是已识别概览场景，不能推广为所有复杂问题都31秒。arXiv仍默认关闭，P2/P3独立成绩不变。
