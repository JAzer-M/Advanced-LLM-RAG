# P2.5：运行前冻结的成对对照与评分规则

本轮12道新问题：4单篇、6跨篇、2不可答。问题和评分点在首次模型调用前冻结；同一已知八篇语料，作者和审阅者均为本代码助手。部分知识点与旧题有交集，不是未见语料、独立第三方盲评或模型训练未见证明。本轮不根据结果调参、改提示词或替换失败题。

## 比较对象与公平边界

- 固定RAG：当前真实main，候选120、Top-10、最多两轮规则补查，rewrite/HyDE关闭；一次新分解、新回答，保持最多一次引用结构修复。
- Agent：复用同一次真实初检（包括固定RAG已有的规则补查及原文账本），只接收问题、原文、来源目录与知识库身份。随后运行现有最多3行动/6模型请求的决策循环，再运行最多4请求的回答/复核。旧答案、Gold和评分点不传入Agent。
- 因此本实验回答“在同一固定RAG检索结果上增加现有Agent层是否改善结果”。不是从零开始的两套最优架构比赛，也不能分离工具补查、不同生成提示、复核各自的因果贡献。
- 同库all-papers-8-20261020、同API模型和公开参数、共享CPU模型。每题固定RAG最多3次请求，Agent新增最多10次；全轮实际最多156次。初检只实际发生一次，路径成本分别分摊一次，实际账单总量不得重复计算。网络失败/截断不自动重试；错误题保留在计划分母。
- 所有请求先落盘；仅完全相同问题、阶段、提示、选项的已完成响应可用于中断续接，失败或进行中的请求不重试。服务级连续连接失败时终止本批，保留尚未运行题。
- 耗时是共享CPU资源预加载后的单次顺序运行时间。Agent路径=共享初检耗时+决策/回答耗时，不包含固定RAG的回答耗时。初载另报，不声明冷启动、并发性能或P95。

## 主要质量评分

逐条对照冻结reference_points、实际答案、该路径拥有的原文及紧邻引用，记录covered/partial/missing/wrong；仅完整正确的covered计1。必要限定应完整保留，不能用词汇命中代替语义判断。

1. 可答题核心覆盖：10题macro，以及covered/total的micro；运行失败、无交付答案的题计0，成功子集另报。
2. 严格通过：核心点全部covered、无实质性错误、无无依据新增事实、关键引用支持充分。拒答或拒交草稿不等于可答题成功。不可答题应明确不能由当前语料确定所问事实且不猜值。
3. 重要断言支撑：拆分事实、数值、条件和比较，记录supported/partial/unsupported/contradicted；正文有证据但未正确引用仍记录引用缺口。程序检查引用编号，不代替语义审阅。
4. 拒答：2道不可答题分别报正确拒答数；10道可答题记录过度拒答/不完整回答；不把“没有跨篇比较原句”当成合理拒答依据。
5. 计划12题和实际成功题两个分母均保留。按同题列RAG胜/Agent胜/平局，变化报百分点和原始计数，不用小样本宣称总体显著改善。

## 检索与成本量化

- 共享初检Top-10计算原始Precision、整体nP、Macro Recall、MAP、MRR；不可答无Gold题跳过。这一组对两条路径相同。
- 对两条路径实际交给生成器的完整证据，分别记录条数、字符数及指定Gold召回。Agent可追加至32段/24000字符，属于可变上下文预算；不得把全部证据召回改善写成同预算Recall@10提升。另保存Agent前10/20及全量指标，但不将20条前缀伪称独立Top-20策略实验。
- 报实际客户端尝试、HTTP POST、成功响应、失败、结束原因、输入/输出/总token、工具次数、停止原因、耗时与预算耗尽。usage缺失单列，不假定为零账单；未核验价格时不换算人民币。
- 真实实际账本与“共享初检分摊到两条路径”的归因表分开，避免双计请求/token。每题只跑一次，不估计服务波动。

## 验收与解读

保留全部结果后再判断当前Agent能否带来质量收益，以及收益是否值得额外成本。若Agent失败更多或质量未改善，如实报告并定位；本轮不通过优化同一新题来美化成绩。旧h01/h10/h11仅作历史开发案例引用，不并入本轮新题分母。
