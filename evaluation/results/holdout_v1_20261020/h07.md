# h07: How does the learning-rate schedule in Attention Is All You Need differ from DCNN, including what triggers the decrease in each paper?

## 回答

当前证据仅能部分回答该问题。

在《Attention Is All You Need》中，学习率按公式随训练过程变化：在前 warmup_steps 个训练步内线性增加，之后按步数的平方根倒数比例下降，所用 warmup_steps = 4000 [1]。这一变化由训练步数触发，而不是由验证误差触发 [1]。

在 DCNN 论文中，所有层使用相同的学习率，并在训练过程中手动调整；其遵循的启发式规则是：当验证误差率在当前学习率下不再改善时，将学习率除以 10；学习率初始化为 0.01，并在终止前降低了三次 [8]。

因此，两篇论文降低学习率的触发条件不同：《Attention Is All You Need》依据训练步数按预设公式调整 [1]，DCNN 则依据验证误差率停止改善而手动下调 [8]。关于 DCNN 是否也采用分阶段预热或其他调度公式，所给证据不足，无法判断。
