# P1 留出评测 v1：运行前评分标准

本次固定 12 题：4 单篇、6 跨篇、2 不可答；前 10 题的英文核心点见题集 `reference_points`。问题、Gold、核心点在首次生成前冻结并记录 SHA-256；模型只收到当前问题和实际主流程生成的上下文。Gold 与核心点不进入分解、检索或最终生成提示。

这是同一八篇语料上的开发流程留出集，未曾用于本轮调参；不是第三方盲评、未见语料泛化或模型预训练未见证明。作者/评审均为本助手，人工逐条阅读原文、输出和引用，不用词汇命中替代语义判断。

## 预先固定的执行条件

- 显式八篇库 `all-papers-8-20261020`，1,397 chunks；原库、旧题/Gold、旧日志和激活指针保留。
- 每路候选与 RRF 120，RRF 常数 60，最终 Top-10；原查询锚点、子题局部 Top-3、最多两轮有条件补查按现有主流程。
- rewrite、HyDE 关闭；每题一次真实新分解及当前 main 检索/重排/最终生成；保留原有最多一次引用结构修复。
- 既有 API 模型、temperature=0、max_tokens=4096、thinking disabled 保留。全轮最多 36 次实际 chat 请求，错误/截断也计入；无自动重试。不执行 oracle、伪造证据或新参数对照。
- 受控线程、离线加载既有 CPU Embedding/BGE；同一进程共享真实模型。运行时间含实际检索/生成，不含共享模型初载，不是冷启动或 P95。
- 实际调用逐次落盘；中断后只复用完全相同提示、选项和输入哈希下已成功的响应，已完成题不再请求。运行错误单独列出，不能悄悄剔除分母。

## 检索指标

直接读取本次实际 main 的 `selected_ids` 计算 P@10、Recall@10、AP@10/RR@10及汇总 MAP/MRR，不另跑会产生改写 API 的默认 evaluation。

Gold 按原有 NFKC、空白合并、大小写归一化，以 source/page/quote 映射当前版本，所有命中 chunk 的 ID 去重并集。逐题 nP=H/min(10,G)，整体 nP=sum(H)/sum(min(10,G))；原 Recall 保持宏平均。两道无 Gold 题跳过检索计分。Gold 非穷尽，未命中指定 Gold 不能自动判回答错误；替代原文支持要单独核对。检索分数不等于回答准确率。

## 答案与引用语义审阅

1. **核心点覆盖**：每个预先列出的 reference point 记 covered / partial / missing / wrong。仅完整且正确的 covered 计 1，其他计 0。每题覆盖率=covered/该题核心点数；主要汇总为 10 道可答题宏平均，另列 micro covered/total。失败题在计划分母中覆盖为 0，成功子集另报。预先写在一个核心点内的必要限定全部满足才计 1。
2. **引用结构**：编号存在、格式完整，沿用现有自动检查；与语义判断独立。
3. **重要断言支撑**：按事实/因果/数值/比较拆分实际答案，核对该断言紧邻或所属段落引用及原文。标 supported / partial / unsupported / contradicted；未引用但在上下文可证的断言仍记录引用缺口。可以合理综合两段来源，不要求存在逐字相同的跨篇比较句。常规转折和拒答措辞不虚增事实断言数。
4. **严格通过**：可答题核心点全部 covered，没有实质性错误、无依据新增事实，关键引用均充分支撑；不可答题明确资料不足且不编造所需数值，必要边界解释正确。核心点漏答、部分支持、过度拒答或新增错误均不严格通过。引用结构通过不能替代此判断。
5. **拒答**：h11 的 Mamba 原文不在八篇库中；h12 所设原始 Transformer 与 VGG D 的同协议 ImageNet 实验未由两文提供。正确拒答无需伪造引用。可答题以“没有直接比较句”为由拒绝可由两篇各自原文综合的结论，记录为过度拒答。
6. **错误与失败**：API/运行错误单列；给出计划 12 题与成功执行题的两个分母。总体严格通过同时列可答题与不可答题，不把拒答题混进检索指标。

## 失败归因与保留原则

先分“指定 Gold 未入最终 Top-10”和“Gold/替代证据已在生成上下文但漏答/误答”；再看分解、主流程已有诊断与补查痕迹。若全局初始候选未完整保存，不声称已经证明是召回器漏召或重排器独自造成。引用错配、合成比较失败、过度拒答和越界编造独立记录；可以一题多因。

本轮只建立可审阅基线、保留缺陷，不调参、不修生产算法、不追加大量论文。结果不能与旧 42 题不同 Gold/题目分布的分数直接解释为提升或退步。之后若用本集优化，应改称开发集并另建留出集。
