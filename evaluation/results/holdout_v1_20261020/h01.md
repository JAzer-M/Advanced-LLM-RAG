# h01: What label-smoothing value does Attention Is All You Need use, and how does the paper say it affects perplexity versus accuracy and BLEU?

## 回答

Attention Is All You Need 使用的 label smoothing 值为 ϵls = 0.1 [1]。论文指出，这会使模型学会变得更不确定，从而损害 perplexity，但会提升 accuracy 和 BLEU 分数 [2]。
