# h05: How does VGG initialize deeper configurations from configuration A, and how does this differ from the per-layer weight initialization reported in DCNN?

## 回答

VGG 在训练更深架构时，用配置 A 的前四个卷积层和最后三个全连接层进行初始化（中间层随机初始化），且不为这些预初始化层降低学习率，允许它们在训练中变化[1]。对于随机初始化的层，权重采样自零均值、方差 10⁻² 的正态分布，偏置初始化为零[7]。

DCNN 则对每一层的权重均从零均值、标准差 0.01 的高斯分布初始化[2]；其第二、第四、第五卷积层及全连接隐藏层的神经元偏置初始化为常数 1[2]，其余层偏置初始化为常数 0[8]。
