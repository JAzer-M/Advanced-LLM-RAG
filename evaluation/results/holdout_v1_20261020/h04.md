# h04: For dense evaluation of an uncropped test image, how does VGG convert its fully connected layers, and how does it reduce the output to final image-level class scores?

## 回答

在 dense evaluation 中，VGG 将全连接层转换为卷积层：第一个 FC 层转为 7 × 7 卷积层，最后两个 FC 层转为 1 × 1 卷积层，随后将得到的全卷积网络应用于整张（未裁剪的）图像[1]。由于全卷积网络在整张图像上输出的是一个通道数等于类别数、空间分辨率随输入图像尺寸变化的 class score map[9]，为得到图像的固定大小类别分数向量，VGG 对该 class score map 进行空间平均（sum-pooling）[9]。
